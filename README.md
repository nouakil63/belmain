# Belmains

La version visuelle 03 est la seule retenue. Les propositions 01 et 02 et les prototypes historiques ont été retirés des fichiers actifs ; ils restent consultables dans l’historique Git.

- `site/` : site statique de présentation publié sur https://belmain.vercel.app/, sans sélecteur de versions.
- `wordpress/belmains/` : première version du thème WordPress installable, avec le design, les médias et les interactions validés.
- `wordpress/README.md` : installation, validation et étapes restantes de migration.

La boutique reste en démonstration. La connexion WooCommerce, les paiements et les formulaires réels seront traités après le choix de l’hébergement.
